## 一、小红书（图文笔记）

**标题**（选一个）



1. 我把一句话拆成七块，寄给了一个人

2. 收到的 "快递" 拆开全是零件，最后一块底下压着一张纸条

3. 拍一张照，就能把一句话藏进一件旧东西里

**正文**

有些话说出来太轻。

写在卡片上像客气，发在微信里像随口一提。我想让它重一点 —— 于是把一盏台灯拆成七块，把那句话压在最里面那块底下，整件当一条链接寄出去。

对面点开链接，先看见的是一件墨色的、没有名字的东西。看得出是 "一件东西"，但说不准是什么。每一块都能往外拉，拉下来的那一刻它才当场恢复原色。拉错方向，那张信的纸边会被撕掉一截 —— 撕痕留在那儿，重拆一次才能补上。

一直拆到最后一块，纸条才从底下抽出来。

灯不是画出来的。我拍了一张照片，Aholo Lux3D 把它变成带材质的模型，再按结构拆成七块真零件（灯泡、灯臂、灯罩、灯头接头、灯杆、底座、电源线）。拆的过程就是信封。

拆完还有三条路：回他一句、把件装回去再寄回去；或者点 "下载 STL 去打印"，七个文件直接丢进切片软件，把这句话真的摆在桌上。

这是群核 Aholo 全球 3D AI 黑客松的参赛作品，叫「无名件」。

在线拆一件：<魔搭链接>

代码：[github.com/HpIahtcthocw/chai-le-ji-gei-ni](https://github.com/HpIahtcthocw/chai-le-ji-gei-ni)

**配图**（4 张，从项目里现截，别用设计稿）



1. 拆件台首屏：95 窗口工位 + 台灯舞台 + 右边寄件单

2. 收件页开场：墨色剪影，一块都还没拆

3. 拆到最里面那块，纸条抽出来的那一下

4. 摊开页：七块带编号和零件名，右下角「下载 STL 去打印」

## 二、X（中英双语，工程记录，5 条 thread）

**1/**

English: I hid a sentence inside a lamp — not written on it. Split it into 7 parts, put the note under the last one, shipped the whole thing as a single link.

中文：把一句话藏进一盏台灯里，不是写在灯上：拆成七块，纸条压在最里面那块底下，整件只当一条链接寄出去。

**2/**

English: The receiver opens it and sees an ink-black thing with no name. Every part pulls out; the second it comes off, it gets its color back. Pull the wrong way and the edge of the letter tears — the tear stays.

中文：收件人点开只看见一件墨色的、没名字的东西。每块都能往外拉，拉下来的瞬间才恢复原色；拉错方向，信的纸边会被撕掉一截，撕痕会留着。

**3/**

English: Nothing is hand-modelled. One photo → `imgTo3D` (200k faces) → `partSplit` → 7 real meshes, coords baked. Task numbers are in the report, not vibes.

中文：形状不是画的。一张照片 → `imgTo3D`（20 万面）→ `partSplit` → 七个真 mesh，坐标已烘焙。任务号写在报告里，不靠感觉。

**4/**

English: Two endings: reply and ship it back (new parcel code, zero generation cost), or export STL and actually print the 7 parts — 13.2 MB of geometry, one file per part, centred at origin.

中文：两个结局：回一句再寄回去（生成新包裹码，不重新生成模型、不烧额度），或者导出 STL 真打出来 ——13.2MB 几何，一块一个文件，几何中心已归零。

**5/**

English: The hard part wasn't splitting, it was making the split *mean* something: pull direction visible but not whether it can move; wrong pulls count; the note names the oldest part; the receipt records 7 parts / 0 hard pulls / 9 s.

中文：难的从来不是 "拆"，是让拆这件事有意义：箭头只说它往哪走、不说它现在能不能走；拽错记一次；纸条上写着 "最旧的一块是哪个"；拆完给一张账单：7 块、硬拽 0 次、用时 9 秒。
