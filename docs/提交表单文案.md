## 项目名

无名件

## 一句话介绍（约 50 字）

拍一张照，那件东西会被拆成零件寄出去；对方一块块拽出来，最后一块里夹着你写的那句话。

## 项目说明（约 200 字）

寄礼物难的不是买东西，是写那句话。写在卡片上太轻，发在聊天框里太随便。

「无名件」换一种载体：上传一张照片，Aholo Lux3D 先把它变成带材质的 3D 形状，再按结构拆成独立零件，装进一个只靠链接传递的包裹。收件人打开链接，看到的是一件被拆散的东西——每个零件各自带方向，按住往外拉，形状一块块还原。顺序错了会留下撬痕，撬痕会撕掉纸条的边；拆到最里面的那块，才翻出寄件人写的那句话，还有一张他随手拍的原图。

拆完可以摊开看零件清单，也可以回一句话，装回去寄回给对方——回信不重新生成模型，不消耗额度。

一句话：把一句话藏进一样东西的零件里，收件人得亲手把它拆开才读得到。

## 技术栈

- 群核 Aholo Lux3D：`imgTo3D`（图片生成带 PBR 的 GLB）+ `partSplit`（按结构拆成独立 mesh），任务号在进度页可查
- 群核 Aholo Viewer：页面里渲染拆分后的模型，四档显示（墨色／原色／套色／线框）
- Next.js + three.js + MediaPipe HandLandmarker（手势抓取在本地跑，画面不出本机）
