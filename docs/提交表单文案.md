# 提交表单文案（待你确认后粘贴）

## 项目名

无名件

## 一句话介绍（约 50 字）

拍一张照，那件东西会被拆成零件寄出去；对方一块块拽出来，最后一块里夹着你写的那句话。

## 项目说明（约 200 字）

寄礼物难的不是买东西，是写那句话。写在卡片上太轻，发在聊天框里太随便。

「无名件」换一种载体：上传一张照片，Aholo Lux3D 先把它变成带材质的 3D 形状，再按结构拆成独立零件，装进一个只靠链接传递的包裹。收件人打开链接，看到的是一件被拆散的东西——每个零件各自带方向，按住往外拉，形状一块块还原。顺序错了会留下撬痕，撬痕会撕掉纸条的边；拆到最里面的那块，才翻出寄件人写的那句话，还有一张他随手拍的原图。

拆完可以摊开看零件清单，也可以回一句话，装回去寄回给对方——回信不重新生成模型，不消耗额度。

一句话：把一句话藏进一样东西的零件里，收件人得亲手把它拆开才读得到。

## 技术栈

- 群核 Aholo Lux3D：`imgTo3D`（图片生成带 PBR 的 GLB）+ `partSplit`（按结构拆成独立 mesh），任务号在进度页可查
- 群核 Aholo Viewer：页面里渲染拆分后的模型，四档显示（墨色／原色／套色／线框）
- Next.js + three.js + MediaPipe HandLandmarker（手势在本地跑，画面不出本机）：捏住往外拉是拆一块，张开手掌停一下整件散开，握拳停一下又拼回去，挥手才是转着看

## 用到的 Lux3D 能力

| 能力 | 用在哪 | 是否真实调用 |
|---|---|---|
| imgTo3D | 寄件人上传照片 → 生成 3D 形状 | 是，任务号 8235025（台灯）、8310067（收音机）、8310695（台扇） |
| partSplit | 把形状拆成可单独拽出的零件 | 是，任务号 8235303 / 8310308 / 8311013 |

## 在线体验

https://chai-le-ji-gei-ni.vercel.app

线上打开就是拆件台（灰底、Win95 窗口，左栏放示例照片与「现成的包」，中栏是能拖转的台灯舞台，右栏是寄件单）。示例照片点一下就能用，写一句话，按「开始拆件」，出来是装箱动画加一条链接。真产物三件都能直接拆（台灯 7 块、老收音机 7 块、台扇 5 块）。现场生成走的是完全无状态的链路：照片在浏览器里压到 1600px 的 JPEG，提交 imgTo3D 拿任务号，前端每 3 秒查一次；粗模出来后提交 partSplit，再查一次；最后把拆分模型的官方 CDN 地址编进包裹链接，收件人打开就能直接拆，服务端不落盘、不需要长驻进程。实测单件：建模 5–10 分钟，拆件约 1.5 分钟，所以页面上写的是「这件事要几分钟，不用守着」。

已知限制：手势要开摄像头，台灯那件在手机上比在鼠标上更好玩；vercel.app 域名在国内直连打不开（DNS 解析被污染到 31.13.94.10，边缘 76.76.21.21 拒绝 TLS），需要代理访问；生成依赖 Aholo 官方接口与配额；现场生成的零件没有零件名，标签只能显示「第 N 块」。

## 参赛者补充

- 一件物品 2 次 Lux3D 任务（生成 + 拆分），不是 3 次；STL 导出只在早期演示件上跑过
- 现场生成链路实跑过一遍：imgTo3D 任务号 8319460（20 credits，5 分钟量级）+ partSplit 8320440（约 100 秒），产物链接在 docs/部署记录.md 里
- 项目里有三件真产物：图生一件（7 块）、收音机（7 块）、台扇（5 块），首页「门口还放着」可直达拆件页
- 所有生成产物与任务号都存在项目里，报告书第九节可复现
