## 七、手势，和一台旧机器的界面

**手势拆件**：摄像头前捏合手指抓住一块，手往外一推，那块就出去了；张手散开，零件全摊在桌上；握拳收拢，装回去。MediaPipe HandLandmarker 的模型与 wasm 都在仓库里，画面不出本机；抓取带 110px 吸附，握拳判定先于捏合，避免握拳被当成抓取；真机测下来，抓着零件转视角时误触 0 帧。

![手势：捏合抓住零件、张手散开、握拳拼回](@./docs/figures/shoushi.png)

**界面不是科技感 HUD**：整套界面按"一台旧机器的说明书"来做——纸底、墨色、一层深绿、等宽字、编号、窗口边框、寄件单与装箱单的表格。界面与物件共用同一年代的语言：拨盘电话、双铃闹钟、老缝纫机摆进这套界面里不违和；换成发光玻璃和霓虹，它们就成了展品，而不是被人用过的东西。
