## 现场生成怎么跑（无状态，2026-11-18 落地）

1. 浏览器把照片压到短边 ≤1600px 的 JPEG（实测 1440×900 截图压后 0.72MB，请求体上限 4.5MB）。
2. `POST /api/gen` 提交 `imgTo3D`（`version: G1`，`faceCount: 120000`，输出 GLB，开 PBR），1–2 秒返回 `taskId`。
3. 前端每 3 秒 `GET /api/gen?id=`，状态 `0 排队 / 1 跑 / 3 成功 / 4 失败`。
4. 拿到粗模 GLB 后 `POST /api/split` 提交 `partSplit`，同样轮询 `GET /api/split?id=`。
5. 拆分产物地址直接写进包裹码的 `u` 字段（只认 `*.kujiale.com` / `*.aholo3d.cn` 白名单），`/p/<码>` 里 three.js 直接跨域加载，服务端不落盘。

## 一个必须先知道的问题：境内打不开

2026-11-18 在本机实测：

| 目标 | 结果 |
|---|---|
| `https://vercel.com` | 200 |
| `https://github.com` / `https://gitee.com` | 200 / 200 |
| `https://chai-le-ji-gei-ni.vercel.app` | 解析到 `31.13.94.10`（典型的劫持结果），连接超时 |
| Vercel 边缘 `76.76.21.21:443` | TLS 握手失败 |
| `https://hpiahtcthocw.github.io` | 404（域名可解析到 185.199.x，TLS 正常） |

结论：`*.vercel.app` 在境内不可达，这个链接主要对挂梯子的人有效；国内评委点不开。

由此带来一个没法在本机消除的验证缺口：本轮部署之后，`vercel curl` 打生产域名同样 `Connection refused`，**线上函数是否真能访问 Aholo 接口，只能靠本地同一套代码的实测结果推断**，不能当场取证。若评委现场点开发报错，页面会显示具体原因（`系统错误` / `提交失败 5xx` / `生成超时了`），不会白屏。

## 已考虑过、目前没走的方案

1. **GitHub Pages 静态版**：`*.github.io` 在本机可通。但静态导出要砍掉 `/api/*`（Next 的 `output: 'export'` 不接受 route handler），现场生成也就没了；免费版要求仓库公开、要推送。
2. **自定义域名指向 Vercel**：需要已有域名；能不能通取决于解析到的边缘 IP。
3. **Cloudflare Pages 直传**：不需要推仓库，但要登录 Cloudflare 账号；`*.pages.dev` 在国内的连通性没实测。
4. **国内对象存储（OSS/COS）+ 域名**：域名要备案，时间上来不及。
5. **全功能长驻部署**：容器 + 对象存储，今晚做不完，且要花钱。
