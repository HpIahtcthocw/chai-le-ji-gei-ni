## 线上跑的是“只读体验版”

| 能点 | 不能点 |
|---|---|
| 首页那件包裹（台灯，7 块） | 寄一件（`/send` 换成说明页） |
| 门口两件示例：台扇（5 块）、收音机（7 块） | 上传照片（`/api/upload` 返回 503） |
| 拆件、方向箭、撬痕、纸条、「最旧的一块」 | 起生成任务（`/api/jobs` 返回 503） |
| 摊开、编号标签、四档显示 | 进度页 `/job/<id>`（本机才有 job 记录） |
| 装盒页 `/s/<码>`、回信页 `/r/<码>` | — |

原因：生成是分钟级任务，本机实现是 `spawn` 独立进程 + 写本地 `public/items`。serverless 没有长驻进程、没有可写目录，也读不到 `.env.local`。

## 一个必须先知道的问题：境内打不开

2026-11-18 在本机实测：

| 目标 | 结果 |
|---|---|
| `https://vercel.com` | 200 |
| `https://github.com` / `https://gitee.com` | 200 / 200 |
| `https://chai-le-ji-gei-ni.vercel.app` | 解析到 `31.13.94.10`（典型的劫持结果），连接超时 |
| Vercel 边缘 `76.76.21.21:443` | TLS 握手失败 |
| `https://hpiahtcthocw.github.io` | 404（域名可解析到 185.199.x，TLS 正常） |

结论：`*.vercel.app` 在境内不可达，所以这个链接主要对挂梯子的人有效；国内评委点不开。

## 已考虑过、目前没走的方案

1. **GitHub Pages 静态版**：`*.github.io` 在本机可通。但静态导出要砍掉 `/api/*`（Next 的 `output: 'export'` 不接受 route handler），`/s/<码>`、`/r/<码>` 也要改成查询参数；而且免费版要求仓库公开、要推送。工作量约一小时以上，且推送需要批准。
2. **自定义域名指向 Vercel**：需要你已有域名；能不能通取决于解析到的边缘 IP。
3. **Cloudflare Pages 直传**：不需要推仓库，但要登录 Cloudflare 账号；`*.pages.dev` 在国内的连通性没实测。
4. **国内对象存储（OSS/COS）+ 域名**：域名要备案，时间上来不及。
5. **全功能长驻部署**：要换容器 + 对象存储，今晚做不完，且要花钱。

## 让评委现场生成的可行改法（还没做）

问题不在 API，在这套实现用了独立进程和本地落盘。可改成：

1. `POST /api/gen` 只提交任务，1–2 秒返回 taskId；前端每 3 秒轮询 `/api/gen/<id>`。每次都是短请求，serverless 够用。
2. 拆件后的 GLB 直接用 Lux3D 的回源 URL 喂 three.js，或加一个流式代理转发，不落盘。
3. 状态自带在链接里（像包裹码），或用免费 KV。
4. 密钥只在服务端 + 限流。

真障碍是等待时间：一次 imgTo3D + partSplit 是分钟级，评委不会等。要么接受“留链接，生成完再来看”，要么降面数先出粗模。
